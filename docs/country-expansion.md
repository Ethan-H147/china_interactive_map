# Country expansion data

Germany, Belgium, Switzerland, the Netherlands, the United States, Canada and Mexico use the existing regional-country.mjs renderer and country registry. Search, parent navigation, selection, satellite appearance, statistics, saved links and layer order share the existing implementation.

Run `npm run build:country-expansion` to fetch or reuse the pinned sources, rebuild the datasets, flags, statistical shading, background land and compact downloads. `ONLY=germany,belgium` scopes the geometry build; it does not change border ownership. In PowerShell set `$env:ONLY='germany,belgium'` before the build and remove it afterwards.

Sources are retained in artifacts/expansion-source, with hashes in scripts/country-expansion-sources.json. A changed upstream file fails validation instead of silently changing administrative boundaries or statistical dates. Review a new release and deliberately update its pin when upgrading.

Germany uses 16 states, 400 districts/independent cities and 10,978 LAU municipalities or municipal equivalents. Belgium uses three regions, ten provinces plus Brussels and 581 municipalities. The Netherlands uses twelve European provinces and 342 municipalities. These are Eurostat GISCO's 2024 boundaries, before Belgium's 2025 municipal mergers. GISCO's non-commercial-use terms apply, with the required © EuroGeographics credit displayed in the map attribution.

Switzerland uses swisstopo's 1 January 2026 boundaries: 26 cantons, 135 districts and 2,110 municipalities, plus two shared territories and eleven cantonal lake areas. Where a canton has no districts, municipalities connect directly to the canton. The shared adapter supports those leaf units beside districts with municipality children.

The US has 50 states, DC and all fourteen overseas territories as first-level places. The five inhabited territories use Census 2025 boundaries; the nine Minor Outlying Islands use the UK/France OpenStreetMap coastline method. [Scope, sources and territory navigation](us-territories.md). Alaska's Aleutian coordinates unwrap across the antimeridian. Canada has ten provinces and three territories from Statistics Canada via the pinned geoBoundaries 2023 release. Mexico has 31 states and Mexico City from INEGI's December 2025 Marco Geoestadístico. Its state envelopes include inland rivers, lakes and coastal lagoons, so the optional water display does not cut holes in administrative geometry. IDs are assigned from official INEGI entity codes: Mexico City is MX-CMX and the State of Mexico is MX-MEX. None of these three datasets includes lower-level administrative divisions.

Population keeps its original reference date: GISCO 2024, Swiss 31 December 2024, US July 2025 estimates, Canadian quarterly estimates and Mexico's 2020 census. GDP is supplied for the seven new countries at the official regional levels; coverage, reference years and calculation methods are documented in [expansion-economy.md](expansion-economy.md). State land area in the Census source is labeled as land area.

All parents dissolve from the same municipal topology. Internal borders use one shared mesh per level. International frontier pairs have one stable owner; existing French and Italian reference lines retain ownership. Continuous outline arcs follow joined reference topology. Reference boundary lines cross large lakes and sea channels independently of coastlines.

Run `npm run test:country-expansion`, `npm run test:europe`, `npm run test:compact` and `npm run test:browser -- country-expansion runtime` after data changes. The tests cover unique IDs, parent chains, inner label points, geometry and chunk counts, population sources, public routes, deep selections, reloads, satellite mode and layer order.

China's public and developer views both load the complete county pack after the initial map. County fills, boundaries and selection edges carry `atlas.motion: 'live'`; the camera preview renderer leaves these layers active throughout navigation. New live geometry should use the same metadata instead of relying on a country-specific exclusion. Run `npm run test:browser -- china-district-motion` to sample rendered district borders during camera movement.

US states (including DC), the five inhabited US territories and all Canadian provinces and territories use the shared flag renderer and viewer. Run `npm run fetch:north-america-flags` to reuse pinned originals or `node scripts/fetch-north-america-flags.mjs --refresh` to deliberately update the Commons artwork and attribution. The source manifest is `dist/data/north-america-flag-sources.json`; lossless local thumbnails open the original SVG when enlarged. Run `npm run test:north-america-flags` and `npm run test:browser -- regional-flags` to verify full coverage and viewer behavior. Belgian sidebar thumbnails use France's 3:2 proportions; the enlarged flag retains its original 15:13 proportions.

Flag source selection uses the explicit subdivision IDs in `scripts/north-america-flag-files.json`, rather than constructing filenames from place names. Georgia is pinned to the US state artwork; the flag validation also checks its blue canton and red/white/red stripes independently of the generated manifest.

Mexico has an optional Lakes & rivers control, initially off. Land, selection targets, international frontiers and the shared state border mesh always use the same water-inclusive envelopes. A separate national SEMARNAT/CONAGUA overlay shows 9,377 water-body polygons and| United States | 65 principal river features, using the same blue water styling as China. The source contains seasonal waters and does not include every small tributary; it is geographic context, not live water levels. Water islands are retained. The 3.9 MB compressed overlay loads on demand, participates in saved views, and releases its map resources when leaving Mexico. Other regional countries can use the same controller by supplying a water file in their map configuration.

`npm run build:mexico-water` fetches or reuses pinned national hydrography and builds the overlay against Mexico's current context. `npm run test:mexico-water` validates lagoon/reservoir points, open-sea exclusion, source hashes, retry and lifecycle behavior. `npm run test:browser -- mexico-water` checks on/off land geometry, blue water, state selection, reloads and country changes on desktop and phone. Boundary snapshots and hydrography source pins remain separate from the 2020 census population series.
