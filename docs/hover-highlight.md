# Shared hover highlight

Settings > Map & movement > Highlight hovered region controls a subtle 10% dark tint blended into the current fill. It is enabled by default and saved through the existing settings system, independently of hover tooltips. Selected regions and quiz states keep their priority; statistical colors keep their relative hues. Thin transparent hit fills receive at most a small visibility floor while hovered, without changing their ordinary opacity. Point settlements and islands without administrative geometry are not treated as polygon fills.

The existing shared overview resolves the pointer once per frame and supplies the same place to the tooltip and renderer. Legacy China, Mongolia, Korea, Japan and archipelago hover handlers no longer perform duplicate lookups. Hover changes feature state in the already visible administrative fill sources; source data, layers and polygon geometry remain unchanged. Moving within the same region writes no additional state. Crossing a boundary clears the previous hover key and sets the new one. Clearing removes only hover state, preserving selection and quiz feedback, and does not rescan selection visibility.

Pointer exit, pointer down, movement start, settings changes, source eviction and country changes clear the highlight. Panning and zooming do not run hover hit tests. Turning off both hover highlighting and hover information skips the shared pointer lookup altogether. No idle animation or paint-property update runs on pointer movement. Indonesia’s split coastal components retain the same logical hover identity.

Checks compile and evaluate the actual MapLibre paint expressions, verify color/selection/quiz priorities and saved settings, inspect the rendered desktop tint, and count hit tests, state writes and geometry sources. Desktop and phone checks cover independent controls, persistence, pointer/touch cleanup and multiple renderer families. Operation counts demonstrate bounded extra work; they are not a universal frame-rate guarantee. The separate intermittent long-session slowdown remains unresolved.
