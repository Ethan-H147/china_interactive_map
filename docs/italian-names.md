# Italian regional names on cards

Cards follow the same hierarchy as Spain: English heading, a distinct Italian name, then labeled regional-language names. South Tyrol displays South Tyrol, Bolzano, and German Bozen on separate lines. Its municipalities separate the retained Italian and German forms too. A sole German name identical to the heading is suppressed under the shared duplicate rule; language labels are plain text.

The existing bilingual Aosta Valley records similarly separate Italian and French. Trentino-South Tyrol uses German Trentino-Südtirol, following the [regional government's German name](https://www.region.tnst.it/). Municipal Italian/German pairs remain grounded in the retained catalogue and the [Bolzano court's bilingual municipality list](https://tribunale-bolzano.giustizia.it/de/competenza_territoriale.page). The Bolzano municipality card uses Bolzano rather than inheriting the province's English South Tyrol label.

The display adapter changes no boundaries, statistics, record identities or Italian audio inputs. Existing German/French forms and the displayed regional forms remain accepted in both typed quiz modes. Sources and raw bilingual catalogue strings remain intact.

Run npm run test:italy-names for data/quiz checks and desktop/phone card verification.
