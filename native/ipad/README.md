# Boundary Atlas — native iPad prototype

Open [START-HERE.md](START-HERE.md) for transfer and Swift Playground instructions. Read [ARCHITECTURE.md](ARCHITECTURE.md) for ownership, country packs, rendering, verification limits and the path to deeper administrative levels.

The runnable app project is **BoundaryAtlas.swiftpm**. It has no external Swift package dependencies and no API credentials. SwiftUI, Metal, UIKit and AVFoundation are supplied by iPadOS. The website and its publishing configuration are unaffected.

Before treating it as a tested iPad app, build and run it in Swift Playground or Xcode on an Apple SDK host. This draft was generated on Windows: geometry/data checks, Swift parsing and reference GPU draws passed, but Apple compilation and device tests have not run.
